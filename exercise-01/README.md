# Ejercicio 01 — Propagación de una onda

Pregunta: **¿Cómo cambia un campo cuando una perturbación se propaga, se repite y pierde energía?**

Cada módulo calcula su distancia a un origen y responde mediante una onda senoidal amortiguada. Los parámetros que afectan la geometría son la posición X/Z del origen, la frecuencia, la amortiguación y la velocidad.

Esta carpeta se completará durante el curso.
